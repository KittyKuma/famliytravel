## 여는 법
- **가장 쉬운 방법:** `index.html` 더블클릭 → 바로 열립니다(빌드 불필요).
- **폰에 설치(PWA)·오프라인까지 쓰려면** 웹서버로 열어야 합니다:
  ```
  cd D:\_MyProject\Osaka
  python -m http.server 8099
  ```
  브라우저에서 `http://localhost:8099` 접속 → (모바일) 메뉴 → **홈 화면에 추가**.
- **인터넷에 올리려면** 폴더 통째로 GitHub Pages / Netlify / Vercel에 올리면 끝(정적 사이트).

## 폰에서 쓰는 법 (가족에게 공유)
1. 위 방법으로 사이트를 폰 브라우저에서 연다.
2. 공유 → **홈 화면에 추가** → 앱처럼 아이콘 생성.
3. 한 번 열어두면 **오프라인(비행기/데이터 없이)에서도** 일정·회화·지도링크 사용 가능.

## 개인정보
체크 상태·ICOCA 잔액 메모는 **그 기기에만(localStorage)** 저장되고 외부로 전송되지 않습니다.
여권번호·결제정보는 저장하지 않습니다.

## 내용 수정
여행별 데이터는 [`js/trips/`](js/trips/) 폴더에 한 파일씩 있습니다.
- [`js/trips/2026-10.js`](js/trips/2026-10.js) — 이번 여행 (`current: true`)
- [`js/trips/2026-07.js`](js/trips/2026-07.js) — 지난 여행 (`archived: true`, 주소 `#/jul/...`)

새 여행을 추가하려면 파일을 하나 더 만들어 `current: true`로 두고, 이전 여행은 `archived: true`와 `slug`를 지정한 뒤 `index.html`·`sw.js`에 파일을 등록하면 됩니다.
체크 상태·메모는 여행별로 따로 저장돼요.
