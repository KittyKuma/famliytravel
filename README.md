## 여는 법
- **가장 쉬운 방법:** `index.html` 더블클릭 → 바로 열립니다(빌드 불필요).
- **폰에 설치(PWA)·오프라인까지 쓰려면** 웹서버로 열어야 합니다:
  ```
  cd D:\_MyProject\Osaka
  python -m http.server 8099
  ```
  브라우저에서 `http://localhost:8099` 접속 → (모바일) 메뉴 → **홈 화면에 추가**.
- **인터넷에 올리려면** 폴더 통째로 GitHub Pages / Netlify / Vercel에 올리면 끝(정적 사이트).

## 폰에서 쓰는 법 (가족에게 공유)
1. 위 방법으로 사이트를 폰 브라우저에서 연다.
2. 공유 → **홈 화면에 추가** → 앱처럼 아이콘 생성.
3. 한 번 열어두면 **오프라인(비행기/데이터 없이)에서도** 일정·회화·지도링크 사용 가능.

### 내용 수정
- 일정·장소·맛집 등 **내용은 여행 데이터 파일만** 고치면 돼요. 코드는 건드릴 필요 없어요.
- 데이터 안의 링크는 `'#/transit'`처럼 적으면, 지난 여행에서는 자동으로 `#/jul/transit`이 돼요.
- 내용을 바꿔 배포할 때는 `sw.js`의 `CACHE` 버전을 올려 주세요.

### 새 여행 추가
1. `js/trips/YYYY-MM.js`를 만들고 `current: true`, `storeNs: '<slug>:'`을 넣어요. 기존 파일을 복사해서 고치면 편해요.
2. 이전 여행은 `current`를 지우고 `archived: true`와 `slug`를 지정해요.
3. 하단 탭(`tabs`)·메뉴(`menu`)·배너(`banner`)는 **새 여행 페이지로** 채워요. 지난 여행은 홈의 "📦 지난 여행"에 자동으로 나와요.
4. `index.html`과 `sw.js`의 `ASSETS`에 파일을 등록해요.

체크 상태·메모는 여행별로 따로 저장돼요.
